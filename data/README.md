# Evidence and synthetic-data directories

- `incoming/`: immutable uploaded/source evidence copies.
- `processed/`: derived parsing and normalisation outputs only.
- `synthetic/`: deterministic fictional demo datasets and hidden evaluation
  ground truth.
- `golden/`: expected inputs/outputs used by tests and evaluation.
- `exports/`: investigator-generated reports; never source evidence.

SUTRA's included data is fictional. Do not place confidential or unauthorized
records in this repository.
